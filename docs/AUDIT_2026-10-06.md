# Public source audit — 6 October 2026

**Baseline:** `bd4850c76d71606175ca1897b6947d9f01a0b16a` in `MasterPlayspots/ourark-world-studio`. The existing Node/static verification passed on that baseline, but the audit found cases its checks did not exercise. A green baseline was therefore insufficient evidence for all advertised editor paths.

**Current status:** corrections and regression checks are being verified on the public audit branch. The new browser/visual-startup and Rust build jobs are still under verification; this report does not record them as passed. Use the final public commit and its CI artifacts before claiming the audit is complete.

## Findings addressed in this change

| Area | Defect and correction | Regression evidence to inspect |
| --- | --- | --- |
| Map project editing | Same-world metadata imports were outside undo history; a deferred point import could interfere with a drag. Project history now tracks metadata and payload together while retaining the current save revision, and point imports reject active drags. | `tests/map-history.test.mjs`, `tests/browser/audit-regressions.browser.mjs` |
| Map persistence | Incrementing an accepted maximum revision could write an unreadable next revision. Saves now reject that transition before writing. Documentation now states that reload restores the last **saved**, not last opened, project. | `tests/map-project.test.mjs`, `dist/map-studio/storage.js` |
| World Studio | The import UI did not accept Map Studio's normal project envelope. It now uses the map-project validator. Text/panel names now invalidate their texture, Add is disabled for external worlds, and unit labels distinguish dioramas from metre-based imports. | `tests/world-studio.test.mjs`, `tests/browser/audit-regressions.browser.mjs` |
| Development server | `.mjs` files had the wrong content type, slashless directories broke relative integration links, and asynchronous route failures could escape request handling. Correct MIME, canonical directory redirects and request-level error handling were added. | `tests/repository.test.mjs`, `tests/browser/audit-regressions.browser.mjs` |
| Realtime rooms | Stopping an idle tick loop could leave inactive sockets without expiry. Durable Object alarms now retain cleanup deadlines across hibernation, with timer cleanup when alarm storage is unavailable. | `tests/edge.test.mjs`; these use local/fake infrastructure, not a deployed Cloudflare acceptance run |
| Simulation | Rejected terrain updates could alter active data; reverse slope checks, taxiing into abrupt terrain and reverse lap progression had incorrect cases. Input validation and JS/Rust rules were corrected, with explicit regression scenarios. | `tests/sim-wasm.test.mjs`, `tests/car.test.mjs`, `tests/plane.test.mjs`, `tests/kart.test.mjs`; updated WASM must match the pinned source build |
| Verification | Browser suites could exit successfully without Playwright; the shared harness assumed Metal, and static import checks missed module forms. Missing browser tooling now fails, Linux uses software WebGL, and literal relative imports are checked across authored modules. | `tests/build-tools.test.mjs`, `scripts/check.mjs`, browser CI |

`npm run test:browser` now requires both public smoke and audit regressions. The narrower `test:browser:public` and older `test:browser:extended` commands remain distinct. CI also captures a Map Studio startup screenshot/snapshot with pinned agent-browser tooling and rebuilds WASM using Rust **1.97.1**, checks its behavior and compares it with the committed bytes. These are required checks, not results asserted by this document.

## Provenance and remaining boundaries

- At the baseline, `npm run verify:source` verified all **528** initial export files. Independent Git-blob checks found no mismatch in unchanged copied files. Only the manifest and three declared generated architecture files were outside its file list. No excluded history, deployment configuration, original scans or kart/globe data bundles were tracked. `PUBLIC_SOURCE.json` remains the original export record; public Git history records these later fixes.
- The core MIT license names **2026 Kevin Fröba**; Three.js/Cesium notices remain separate. The CSV filtering fixture includes source/credit strings and placeholder localhost/media paths, without the referenced media. Those values do not establish real-world ownership or reuse rights.
- The layer editor still has temporary page state, JSON export and **no UI re-import or local restore**. This limitation is documented, not implemented away by this audit.
- Headless/software browser checks do not establish physical-device performance. Safari, Firefox, phones, accessibility, sustained memory/FPS and real user work require separate evidence.
- Hosted authentication, Cloudflare Durable Object behavior, service configuration, network load and operating cost remain separate from local/fake-server tests. Kart/globe datasets and optional services remain excluded or require setup.
- Proposed use-case success criteria are still hypotheses. No customer time saving, production player capacity or general geometric-accuracy claim follows from these fixes. See [VALUE_AND_VALIDATION](VALUE_AND_VALIDATION.md) and [RELEASE_STATUS](RELEASE_STATUS.md).
